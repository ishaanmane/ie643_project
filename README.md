# Handwritten Document Binarization with Sauvola

This project applies Sauvola adaptive thresholding to handwritten document images to convert them into binary black-and-white versions.

The main script is `sauvola.py`, and the generated binarized outputs are saved in the `binarized_sauvola/` folder.

## Project goal

The goal of this project is to preprocess scanned or photographed handwritten notes so that text becomes easier to read and analyze. The Sauvola method is especially useful for document images with uneven illumination and varying background intensity.

## Repository structure

- `sauvola.py` — main Sauvola binarization script
- `data/` — source input images
- `binarized_sauvola/` — output binary images generated by the script
- `binarized_sauvola/compare/` — optional side-by-side original vs. processed image comparisons

## How the script works

The script:

1. Reads an image from the `data/` directory or a single specified file.
2. Converts it to grayscale.
3. Detects whether the background is dark or light.
4. Applies Sauvola adaptive thresholding using the selected window size and k value.
5. Saves the resulting binary image to the output directory.

## Requirements

Install the dependencies before running the script:

```bash
pip install numpy pillow scikit-image
```

## Usage

Run the script on a single image:

```bash
python sauvola.py --image data/your_image.jpg
```

Run the script on all images in the dataset with a step size:

```bash
python sauvola.py --step 10
```

Use custom threshold parameters:

```bash
python sauvola.py --image data/your_image.jpg --window 31 51 75 --k 0.1 0.2 0.35
```

Generate side-by-side comparison images:

```bash
python sauvola.py --step 10 --compare
```

## Output

The output images are stored in the `binarized_sauvola/` directory. If `--compare` is enabled, comparison images are also saved in `binarized_sauvola/compare/`.

## Notes

- Dark-background images are automatically inverted when needed.
- The script supports multiple window sizes and `k` values, which allows tuning the binarization behavior.
- This project currently focuses on preparing binary document images for further processing or OCR workflows.
